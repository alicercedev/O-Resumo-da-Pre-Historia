# 🌍 A Evolução Humana: Das Caravelas à Navegação Digital

**Data de produção:** Setembro de 2025

Projeto desenvolvido para o **Casa Aberta da ETEC de Poá**, com o tema **"A Evolução Humana: das Caravelas à Navegação Digital"**.  
Esta parte do projeto aborda **a Pré-História**, destacando as principais **invenções e descobertas** que marcaram o início da evolução humana.

---

## 💻 Sobre o Projeto

O site foi desenvolvido utilizando **HTML, CSS e JavaScript**, com uma navegação em **scroll vertical** que conduz o visitante pelas **invenções pré-históricas**.  
Cada seção apresenta **objetos, datas e eventos interativos**, permitindo ao usuário explorar de forma visual e educativa como surgiram as primeiras tecnologias da humanidade.

---

## 🧭 Funcionalidades

- Scroll contínuo para explorar os períodos da Pré-História  
- Interatividade com elementos e invenções da época  
- Animações leves e responsivas  
- Design educativo e imersivo para apresentações presenciais  

---

## 🧑‍💻 Tecnologias

- **HTML5** – Estrutura e conteúdo  
- **CSS3** – Estilo e layout responsivo  
- **JavaScript** – Interatividade e animações
